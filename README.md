## 🚀 Capstone Project — Waze User Churn Prediction

The final module is an end-to-end data analytics project predicting 
user churn for the Waze navigation app.

**What I did:**
- Performed comprehensive Exploratory Data Analysis (EDA)
- Conducted hypothesis testing — T-test & Chi-squared
- Built and evaluated a Logistic Regression model
- Delivered data-driven retention recommendations

**Tools used:**
Python | Pandas | NumPy | Matplotlib | Seaborn | Scikit-learn
