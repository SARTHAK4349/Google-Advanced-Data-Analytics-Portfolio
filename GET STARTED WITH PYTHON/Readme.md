# Get Started with Python

Course two of seven in the Google Advanced Data Analytics Professional Certificate program.

### Course Description

Discover how the programming language Python can power your data analysis. Learn core Python concepts, such as data types, conditional statements,functions,loops, and different data structures.

https://www.coursera.org/learn/get-started-with-python?specialization=google-advanced-data-analytics

### Module 1: Hello, Python! 

You’ll start with exploring the basics concept of Python programming and understand why Python is considered a powerful tool for data analysis. You’ll learn about Jupyter Notebooks, an interactive environment for both coding and visualizations. You’ll investigate how to use variables and data types to store and organize your data; and, you'll begin practicing some important coding skills.

### Module 2: Functions and conditional statements

Next, you’ll discover how to call functions to perform actions on your data. You’ll also learn how to write conditional statements to tell the computer how to make decisions based on your instructions. And you’ll practice writing clean code that can be easily understood and reused by other data professionals.

### Module 3: Loops and strings

After that, you’ll learn how to use iterative statements, or loops, to automate repetitive tasks. You’ll also learn how to manipulate strings using slicing,formatting, indexing.

### Module 4: Data structures in Python

Then, you’ll explore fundamental data structures such as tuples, lists, dictionaries, sets, and arrays. Thereafter, you’ll learn about two of the most widely used Python tools for advanced data analysis: NumPy and Pandas. 

### Module 5: Course 2 end-of-course project

At the end of this course, you will use everything you have learned about Python so far into work with an end-of-course project. You will select a business problem from a list of options and use the given data to solve the problem. This project is an opportunity to demonstrate your skills and build a portfolio you can use to showcase your work to potential employers.
