# Go Beyond the Numbers: Translate Data into Insights

Course three of seven in the Google Advanced Data Analytics Professional Certificate program.

### Course Description

Learn the fundamentals of data cleaning and visualizations and how to reveal the important stories that live within data.

https://www.coursera.org/learn/go-beyond-the-numbers-translate-data-into-insight?specialization=google-advanced-data-analytics

### Module 1: Find and share stories using data

You will explore different ways to visualize data and choose among them to suit the type of data you’re representing and the one best for your audience. You’ll learn about benefits of data cleaning and how it can help you tell stories. You’ll also go over steps of EDA process. There are trends and stories hidden among the numbers and tables inside every dataset. 

### Module 2: Explore raw data

For this part of the program, you will be making sense of raw data by using powerful functions and libraries in Python. You will learn to perform EDA practices of discovering and structuring using Python, and you’ll discover that finding stories using EDA and the PACE workflow is all about gaining a thorough understanding of your data. 

### Module 3: Clean your data

At this point in the course, you’ll know what is in your dataset, next in this part of the program, you will learn three more EDA practices: validating, cleaning and joining. You will learn the importance of performing these practices, and you’ll practice using Python notebooks to clean, validate, and join data. 

### Module 4: Data visualizations and presentations

Once you have learned how to find the story and clean the data, it’s time to share story with others. To present it in ethical, accessible, and professional way, you will learn to use Tableau, one of the best visualization means for data scientists, at an advanced level.

### Module 5: Course 3 end-of-course project

To conclude this part of the program, you will demonstrate what you’ve learned in an end-of-course project. You will select a scenario outlining a business challenge, and you will be tasked with using the data provided to solve the problem. The concepts and skills you will learn in this part of the course will be critical to your success as a data analyst in the future.
