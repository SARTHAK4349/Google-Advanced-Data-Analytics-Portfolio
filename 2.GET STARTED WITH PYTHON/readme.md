# Get Started with Python

Course two of Eight in the Google Advanced Data Analytics Professional Certificate program.

### Course Description

Discover how the programming language Python can power your data analysis. Learn core Python concepts, such as data types, conditional statements, functions, loops, and data structures.

https://www.coursera.org/learn/get-started-with-python?specialization=google-advanced-data-analytics

### Module 1: Hello, Python! 

You’ll begin by exploring the basics of Python programming and why Python is such a powerful tool for data analysis.  You’ll learn about Jupyter Notebooks, which is an IDE used for coding and visualization. You’ll learn how to use different data types to store and organize different type of data; and, you'll begin practicing some important coding skills.

### Module 2: Functions and conditional statements

Next, you’ll discover how to call functions to perform useful actions on your data. You’ll also learn how to write conditional statements to tell the computer how to make decisions based on your instructions. And you’ll practice writing clean code that can be easily understood and reused by other data professionals.

### Module 3: Loops and strings

After that, you’ll learn how to use loops or iterative statement, to automate repetitive tasks. You’ll also learn how to manipulate strings using slicing, indexing, and formatting. 

### Module 4: Data structures in Python

Then, you’ll explore fundamental data structures such as lists, tuples, dictionaries, sets, and arrays. Thereafter, you’ll learn about two of the most widely used and important Python tools for advanced data analysis: Pandas and NumPy.

### Module 5: Course 2 end-of-course project

At the end of this course, you will put everything you have learned about Python so far into action. You will select a business problem from a list of options.This project is an opportunity to demonstrate your skills and build a professional portfolio you can use to showcase your work to future employers.
